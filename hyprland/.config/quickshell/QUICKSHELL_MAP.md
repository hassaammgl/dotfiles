# Quickshell Config Map (Verified)

This document maps the Hyprland Quickshell configuration at `hyprland/.config/quickshell/` (symlinked from `~/.config/quickshell`).

## 1) File tree with purpose

Root (`shell.qml` is entry point):

- `shell.qml` — Entry Scope. Instantiates all top-level windows/components (Bar, Notifications, NotifSidebar, LauncherOverlay, PowerOverlay, MediaOverlay, ScreenshotOverlay, WallpaperOverlay, GifOverlay, KeybindsOverlay, ClipboardOverlay, EmojiOverlay, LockOverlay, OsdOverlay, DashOverlay, DesktopWidgets, ControlCenter). IPC handlers (targets: `control`, `launcher`, `power`, `wallpaper`, `notifs`, `keybinds`, `clipboard`/`toggleDelete`, `emoji`, `gif`, `media` + media controls playPause/next/prev/stop) toggle/show/hide via `OverlayState`.
- `Bar.qml` — Bar panel (Variants per screen). PanelWindow WlrLayershell namespace `quickshell-bar`, anchors by `BarState` (edge/vertical). Sizes: vertical width 44, horizontal height 38 (implicit). GridLayout 9 cols/rows, spacing 6, margins 8. Modules: `Launcher`, `Workspaces`, spacer, `Clock`, spacer, `Tray`, `StatusIcons`, `Power`. IPC `bar` (toggle/show/hide/cycleEdge/setEdge).
- `BarState.qml` (Singleton) — `edge` ("left"/...), `visible`, `vertical`. `cycle()` rotates edges. Persists to `Quickshell.statePath("bar.json")` via FileView+JsonAdapter (`edge`, `visible`); default on FileNotFound.
- `OverlayState.qml` (Singleton) — Visibility flags: launcher,power,wallpaper,notifs,keybinds,clipboard,emoji,clipboardDelete,gif,media,screenshot,dashboard,controlCenter. `close()` clears all; toggle/show helpers (e.g. `toggleClipboard(del)`).
- `Theme.qml` (Singleton) — Design hub. Wallust JSON from `~/.cache/wallust/quickshell.json` (FileView watch) -> `pal`. Exposes `colors`, `font` (ui "Adwaita Sans", mono/icon "JetBrainsMono Nerd Font"), `type`, `space`, `r`, `motion` (durations+easing ints), `icons` (glyphs), `bar`, `osd`. Helpers `mix/withAlpha/barReserve/osdX/launcherCols/panelWidth`.
- `Colors.qml` (Singleton) — Bridge mapping Theme colors to legacy names (`color0..color15`, `surface`, `accent`, `secondary`=accentStrong, `tertiary`=accent, `fontFamily` hardcoded "JetBrainsMono Nerd Font").
- `Notifications.qml` — NotificationServer (keepOnReload, actions/body/image/persistence). On notify: track, `NotifState.record`, expire oldest if >5. `timeoutFor` (Critical 0, Low 3500, else 5000; honors expireTimeout). `accentFor` by urgency. Top-right PanelWindow (WlrLayershell overlay), ListView bottom-to-top, cards animate/drag-dismiss, drain timer paused on hover/drag. Dismiss/expire via server.
- `NotifState.qml` (Singleton) — History array (max 50), dedupe by nid, persist to `Quickshell.statePath("notif-history.json")` (JsonAdapter payload). Helpers `accentFor/tagFor/timeAgo`, `removeAt/clear`.
- `NotifSidebar.qml` — Right sidebar overlay when `OverlayState.notifs`, scrim+focus grab+Escape. Card width `Theme.panelWidth`, list of history; empty shows `Mascot` (`empty.png`). Per-item icon/image/initial, timeAgo, body max 3 lines, dismiss, Clear all.
- `LauncherOverlay.qml` — App launcher full-screen. Filters `DesktopEntries.applications` (noDisplay, match name/genericName/comment/id/keywords), sort, slice 36. Grid 6 cols (cell 118), 3 rows visible (cellHeight 112). Search navigation arrows/Enter/Escape. Launch via `entry.execute()`, close.
- `PowerOverlay.qml` — Session actions (lock/logout/sleep/reboot/power). Starts at power (index 4). Left/Right/Enter/Escape, focus grab. `run`: lock uses `LockState.lock()`, logout `Hyprland.dispatch("hl.dsp.exit()")`, others `systemctl` commands.
- `MediaOverlay.qml` — Media overlay + cava visualizer. When `OverlayState.media`, runs `stdbuf -oL cava -p ${cavaConf}` (stdout SplitParser `;` ints 0-100) -> updates `levels`, `maxLevel`, `tick`. Actions (prev/play-pause/next/stop/raise) enabled by `MediaState`. Navigation/Space/Enter/Escape, focus grab. Timer updates position when playing. Shows art/title/artist/identity, progress bar, time, cava bars, action tiles.
- `MediaState.qml` (Singleton) — MPRIS player (first playing or last), fallback to Hyprland toplevels (mpv/vlc/celluloid). Properties `ready/playing/title/artist/art/identity/length/position/progress`. Methods `toggle/next/prev/stop/raise/seekRatio/fmt`.
- `ScreenshotOverlay.qml` — Screenshot UI. Modes `region/window/full` (via `ScreenshotState.phase/mode`), selection handled by external script flow; UI shows pick/preview states, actions (full/region/window -> copy/save/both). Focus grab + shortcuts. External: calls `screenshot-capture.sh` via ScreenshotState.
- `ScreenshotState.qml` (Singleton) — Screenshot flow. `phase` ("pick"|"preview"), `lastPath` (`~/.cache/quickshell/last-screenshot.png`), `pendingMode`, `tick`. `script` points to `~/.config/hypr/scripts/screenshot-capture.sh`. `start(mode)` hides overlay, delays 280ms, runs capture Process; on exit (0) sets preview + shows overlay, else returns to pick. `copy/save/both` run `wl-copy`/`cp` + `notify-send`. Creates dirs as needed.
- `WallpaperOverlay.qml` — Wallpaper picker (PathView carousel). Scans `wallDir = ~/Pictures/Wallpapers` via `find` (prunes `.git`, `current`), collects image files (*.jpg/jpeg/png/webp/gif), sorts by name. Reads current via `readlink -f ${wallDir}/current`. Carousel (PathView) with 3-path attributes (zOrder/itemScale/itemOpacity/rot), card size `cardW = min(820, width*0.5)`, `cardH = min(500, height*0.56)`. Shows preview, AnimatedImage plays only for selected GIF when open. Navigation arrows/keys/Wheel, Enter applies via `bash ${wallScript} file <path>` (script `~/.config/hypr/scripts/wallpaper.sh`), Escape closes. Focus grab. Uses Colors/Theme; hardcoded sizes/radii/animations (e.g. highlightMoveDuration 280, flickDecel 1200, tilt 58°, card radius 14/18, font 9/12/28).
- `GifOverlay.qml` — Video→GIF converter + picker. Scans `clipDir = ~/Pictures/WallpaperVideos` for video files (*.mp4/webm/mkv/mov/m4v/avi) via `find -maxdepth 1`. Generates thumbs via `bash ${thumbScript}` (writes to `~/.cache/quickshell/gif-thumbs/*.jpg`), ticks `thumbsTick` to refresh. For selected clip, probes with `ffprobe` (duration,size) to show info (trim note if >20s). Phases: `pick`/`converting`/`done`/`error`. `startConvert(path, apply)` runs `bash ${convertScript} [--set] <path>` (outputs log to `convertLog`), sets `lastVideo/lastGif`. Done state offers Set wallpaper (runs `wallpaper.sh file <gif>`), Delete source (`rm` + notify), or Close. Escape cancels converting or closes. Carousel same visual style as WallpaperOverlay. External scripts: `gif-thumbs.sh`, `video-to-gif.sh`, `wallpaper.sh`. Hardcoded card sizes, radii, durations (280ms), font sizes.
- `KeybindsOverlay.qml` — Keybind cheatsheet. Reads `~/.config/hypr/scripts/keybinds.txt` via FileView (watchChanges). Parses lines: detects bind lines by spacing + key tokens (SUPER/ALT/CTRL/SHIFT/XF86/Print/LMB/RMB) -> groups into sections (defaults to "General"); else new section. Search filters. UI stage width 640 max, search 420. Uses Colors font sizes 12/13/14/15/28.
- `ClipboardOverlay.qml` — Clipboard history. Refresh runs `cliphist list` (Process). Parses lines: splits on first tab -> `preview` (compact), marks `image` if contains `[[ binary data`. ListView shows entries (icon  or ), search filters, current highlighted. Actions: copy (if not del) runs `printf '%s\n' "$line" | cliphist decode | wl-copy`; delete runs `printf '%s\n' "$line" | cliphist delete` (removes locally). Delete mode toggled by `OverlayState.clipboardDelete` (del). Shortcuts: Enter activates, Ctrl+D/Delete removes selected (when search empty or general), Escape closes. External deps: `cliphist`, `wl-copy`. UI uses Colors, stage 640 max, search 420, list height up to 460/55% of height, item height 48, radius 12.
- `EmojiOverlay.qml` — Emoji picker. Loads `emojis.json` via FileView (watchChanges) -> `all` array (854 items). Items filtered by query against `g,n,k`, sliced to 80. Grid 10 cols × cell 72, 4 rows visible (height cellHeight*4). Shows current emoji (Noto Color Emoji 34) and name. Navigation arrows/Enter/Escape. Pick copies via `wl-copy <emoji>`. Hardcoded grid/cell, max 80 results, font sizes 13/14/15/28/34.
- `LockOverlay.qml` — Lockscreen. Uses `WlSessionLock` + `WlSessionLockSurface`, locked bound to `LockState.locked`. Background is `~/Pictures/Wallpapers/current` (Image fill crop) + scrim `Theme.withAlpha(Theme.colors.background, 0.55)`. Shows lock icon, time (`Time.hour:minute`), ampm, longDate. Password field (echoMode toggle via `LockState.reveal`, shows eye icons /), connects to `LockState.currentText/unlockInProgress/showFailure/locked`. On accepted calls `LockState.tryUnlock()`. Shows "wrong password" on failure, displays username bottom. Uses Theme/Colors, PAM via LockState. External: wallpaper current, PAM config.
- `LockState.qml` (Singleton) — Lock/auth state. `locked`, `currentText`, `unlockInProgress`, `showFailure`, `reveal`. `lock()` sets locked (clears state). `tryUnlock()` starts `PamContext` (config dir `~/.config/quickshell/pam`, config `password.conf`, user from env). On PAM message responds with `currentText` if required; on Completed sets locked false on Success else failure; on Error sets failure. Clears state on locked change.
- `OsdOverlay.qml` — OSD (volume/brightness/mic). IPC `osd` with volumeUp/Down/Mute, micMute, brightnessUp/Down (calls `OsdState.*`). PanelWindow bottom-left, visible bound to `OsdState.visible`, implicit size `Theme.osd.width/height`, margins bottom xxl, left `Theme.osdX(screen.width)`. Card shows icon (dimmed when muted), `Slider` bound to `OsdState.value`, sets corresponding setter (bri/mic/vol) with ping false on drag apply. Right text shows "mute" or percent. Animations via Theme motion fast.
- `OsdState.qml` (Singleton) — OSD state + controls. `visible`, `kind` ("volume"|"brightness"|"mic"). Pipewire: `sink/source/ready/muted/vol/micReady/micMuted/micVol`, `sinks` list (non-stream). Backlight: `FolderListModel` scans `/sys/class/backlight/*`, reads `brightness` and `max_brightness` via FileView (`briView`), computes `rawBri/maxBri/bri/device`. Derived `value`, icons, `dimmed`, `percent`. `PwObjectTracker` tracks nodes. Timer hide 1400ms. Methods: `show(kind)`, `nodeLabel`, setters clamp/unmute/call show; `setBri` also runs `brightnessctl set %p%` and reloads FileView. Up/Down/Mute methods.
- `DashOverlay.qml` — Dashboard overlay. Visible when `OverlayState.dashboard`. Focus grab + Escape closes, Enter opens `kitty btop`. Panel centered (680x480 max), Card with radius `Theme.r.lg`, opacity/scale animations (160/180ms). Shows host label, load/uptime, CPU/mem/disk/net meters (uses `DashState` values), top processes list (up to 18 from Host), footer hint. Colors from Colors/Theme (some font sizes 10-18 hardcoded). Opens btop on Enter or button.
- `DashState.qml` (Singleton) — Facade over `Host`. Exposes cpuPct/corePcts/memPct/swapPct/memLabel/swapLabel/diskPct/diskLabel/loadLabel/uptimeLabel/hostLabel/downBps/upBps/procs. Delegates `fmtBytes/fmtSpeed` to Host.
- `DesktopWidgets.qml` — Desktop widgets layer (always-on). PanelWindow visible when `WidgetState.enabled`, WlrLayershell namespace `quickshell-widgets`, layer Bottom, no keyboard focus. Anchors by `WidgetState.corner` (top/bottom + left/right), margins 20, scale `s = clamp(WidgetState.scale, 0.75,1.35)`, `cardW = round(236*s)`. Components: `SoftCard` (rect with radius 16, border color0, body padding 12, optional catchClicks, emits hideRequested/activated; right-click hides), `MeterRow` (label/value + progress bar). Shows Clock card (greeting optional via `greetingFor`, time h:mm AP, date ddd · d MMM yyyy, uptime if present), Calendar (month + 7-day row with today highlight), Stats (CPU/mem/disk meters, battery if laptop), Media card (art or Mascot media.gif, title/artist, progress if length>0, prev/play-pause/next, close), Mascot column (speech bubble with dynamic text: listening/cpu brrr/greeting, mascot image by `WidgetState.character`, maxH 170*s, click cycles character, middle cycles corner, right hides). IPC `widgets` target exposes toggle/show/hide/cycle/corner/clock/calendar/stats/media/mascot/greeting/reset (mutates WidgetState). External: UPower displayDevice for battery. Hardcoded radii (12/14/16), font sizes scaled, durations 180/280ms.
- `WidgetState.qml` (Singleton) — Widget state persisted to `Quickshell.statePath("widgets.json")` (JsonAdapter). Properties: `enabled`, `character` (one of `characters` list: session.gif, media.gif, dashboard.gif, empty.png), booleans `showClock/showCalendar/showStats/showMedia/showMascot/showGreeting`, `corner` ("bottom-right" etc.), `scale` (real). Methods `toggle/cycleCharacter/cycleCorner/resetAll`.
- `Host.qml` (Singleton) — System metrics. Polls bash every 2000ms when `needed` true (`OverlayState.dashboard || (WidgetState.enabled && (showStats||showClock))`). Script reads: `/proc/stat` (CPU+cores), `/proc/meminfo`, `df -h /`, net bytes from active iface (`ip route get 1.1.1.1` + fallback), `/proc/loadavg`, `uptime -p`/fallback, `hostname`, `ps -eo pid,user,%cpu,%mem,rss,comm --sort=-%cpu | head -18`. Computes deltas for CPU/core % and down/up bps. `fmtBytes/fmtSpeed`. Stores last values.
- `Time.qml` (Singleton) — Time via `SystemClock` (Minutes). Exposes 12h hour (0->12), minute, ampm, weekday (ddd), day (d), month (MMM), formatted strings (vertical/horizontal/alt*/longDate).
- `emojis.json` — Emoji list (854 entries) with fields `g`, `n`, `k` (emoji, name, keywords). Loaded by EmojiOverlay.
- `cava-media.conf` — Cava config: framerate 30, bars 24, autosens, pipewire input (auto), raw stdout ascii max 100, stereo, smoothing (monstercat/waves/gravity/noise_reduction).
- `assets/` — `dashboard.gif`, `empty.png`, `media.gif`, `session.gif`, `README.txt`.
- `Components/` — Reusable QML: `Capsule.qml` (rect uses Theme.r.md, colors by active), `Card.qml` (Surface radius Theme.r.lg, alpha 0.96), `Divider.qml` (1px, Theme.colors.border opacity 0.7), `IconButton.qml` (item Theme.bar.item, bg changes on hover/active, icon uses Theme.font.icon/Theme.bar.icon), `Popup.qml` (slides in from left, Card body width panelW), `Scrim.qml` (fills, strength controls alpha), `SectionHeader.qml` (caption, muted, letterSpacing 0.4), `Slider.qml` (track 6px pill, thumb 12px, applies on press/move/wheel step 0.05), `Surface.qml` (rect with radiusSize, alpha, outlined border), `Toggle.qml` (42x22 pill, knob slides 16x16, anim fast).
- `modules/` — Bar/widgets: `Audio.qml` (bar button + PopupWindow with volume/mic sliders, output device list bound to `OsdState.sinks`, sets Pipewire.preferredDefaultAudioSink), `BarButton.qml` (vertical/horizontal layouts, active/hover states, emits clicked/wheel), `Battery.qml` (UPower, shows icon by percent+charging, percent label), `Bluetooth.qml` (Bluetooth service, powered/connectedCount/deviceList sorted, PopupWindow with toggle+scan+pair/connect/disconnect flows), `Brightness.qml` (bar button + PopupWindow with PopSlider bound to `OsdState.bri`, wheel adjusts), `Capsule.qml` (empty Item placeholder in modules), `Clock.qml` (toggles showDate, formats via Time, vertical/horizontal), `Cpu.qml` (BarButton opens Dashboard on left, btop on right), `Launcher.qml` (Capsule wrapping BarButton, toggles launcher), `LevelBar.qml` (expandable vertical/horizontal level bar with icon/click/wheel/drag), `Mascot.qml` (AnimatedImage or Image from assets, respects playing/maxH, animated if gif/webp), `Network.qml` (Networking/Wifi/Bluetooth-like UI, large module with popups, passphrase entry, scanning/connect; uses Colors heavily), `PopSlider.qml` (larger track 8px, thumb 14px, step 0.05), `Power.qml` (Capsule+BarButton toggles power), `StatusIcons.qml` (GridLayout of Bluetooth/Network/Audio/Brightness/Cpu/Widgets/Battery inside Capsule), `Tray.qml` (SystemTray items, shows icons, click handlers activate/secondary/display menu), `Widgets.qml` (BarButton toggles WidgetState, right-click cycles character, middle resets), `Workspaces.qml` (Hyprland workspaces, occupied map, generates wsIds up to max>=5, draws numbered pills, dispatches focus).
- `pam/password.conf` — PAM: `auth required pam_unix.so`, `account required pam_unix.so`.
